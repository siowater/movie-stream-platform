# UI/UXデザイン

## デザイン方針

Udemyを参考にした、シンプルで使いやすい動画配信プラットフォームのUI/UXを目指します。

## カラーパレット

### メインカラー
- **プライマリ**: 深い青（#1E40AF） - ボタン、リンク、アクセント
- **セカンダリ**: グレー（#6B7280） - テキスト、ボーダー
- **背景**: 白（#FFFFFF） - メイン背景
- **背景（ダーク）**: ライトグレー（#F9FAFB） - セクション背景

### アクセントカラー
- **成功**: 緑（#10B981） - 完了状態など
- **警告**: オレンジ（#F59E0B） - 注意喚起
- **エラー**: 赤（#EF4444） - エラー表示

## タイポグラフィ

- **見出し**: 太字、大きめのフォントサイズ
- **本文**: 読みやすいフォントサイズ（16px以上）
- **キャプション**: 小さめのフォントサイズ、グレー系

## ページ構成

### 1. トップ画面（コース一覧ページ）

#### レイアウト
```
┌─────────────────────────────────────┐
│          ヘッダー                    │
├─────────────────────────────────────┤
│                                     │
│    ┌─────┐  ┌─────┐  ┌─────┐      │
│    │コース│  │コース│  │コース│      │
│    │カード│  │カード│  │カード│      │
│    └─────┘  └─────┘  └─────┘      │
│                                     │
│    ┌─────┐  ┌─────┐  ┌─────┐      │
│    │コース│  │コース│  │コース│      │
│    │カード│  │カード│  │カード│      │
│    └─────┘  └─────┘  └─────┘      │
│                                     │
└─────────────────────────────────────┘
```

#### コースカードのデザイン
- **サムネイル画像**: 上部に配置、16:9のアスペクト比
- **コースタイトル**: サムネイル下、太字
- **講師名**: タイトル下、小さめのテキスト
- **ホバー効果**: カードが少し浮き上がる（shadow-lg）
- **クリック可能**: カーソルがポインターに変わる

#### レスポンシブデザイン
- **デスクトップ**: 3列グリッド
- **タブレット**: 2列グリッド
- **モバイル**: 1列グリッド

### 2. コース詳細ページ

#### レイアウト
```
┌─────────────────────────────────────┐
│          ヘッダー                    │
├─────────────────────────────────────┤
│  ┌──────────┐  ┌──────────────┐   │
│  │          │  │ コースタイトル   │   │
│  │ サムネイル │  │ 講師名         │   │
│  │          │  │              │   │
│  └──────────┘  │ 説明文        │   │
│                │              │   │
│                │ [コースを見る] │   │
│                └──────────────┘   │
│                                     │
│  セクション一覧                      │
│  - セクション1 (3動画)              │
│  - セクション2 (2動画)              │
│  - セクション3 (1動画)              │
└─────────────────────────────────────┘
```

#### 要素の説明
- **サムネイル**: 左側に大きく表示
- **コース情報**: 右側に配置
- **「コースを見る」ボタン**: プライマリカラー、大きく目立つ
- **セクション一覧**: コース情報の下に配置、折りたたみ可能

### 3. 動画視聴ページ

#### レイアウト
```
┌─────────────────────────────────────┐
│          ヘッダー                    │
├──────────┬──────────────────────────┤
│          │                          │
│ セクション │     動画プレーヤー        │
│ リスト    │     (YouTube埋め込み)    │
│          │                          │
│ - セク1  │                          │
│   ✓動画1 │                          │
│   →動画2 │                          │
│   動画3  │                          │
│          │                          │
│ - セク2  │                          │
│   動画1  │                          │
│   動画2  │                          │
│          │                          │
└──────────┴──────────────────────────┘
```

#### セクションリスト
- **左サイドバー**: 固定またはスクロール可能
- **セクション**: 折りたたみ可能、現在のセクションは展開
- **動画アイテム**: 
  - 現在視聴中: アクセントカラーでハイライト
  - 視聴済み: チェックマーク表示
  - 未視聴: 通常表示
- **動画タイトル**: クリック可能、動画を切り替え

#### 動画プレーヤー
- **YouTube埋め込み**: 16:9のアスペクト比を維持
- **レスポンシブ**: 画面サイズに応じて調整
- **次の動画への遷移**: 動画終了時に自動または手動で次の動画へ

## コンポーネント設計

### 共通コンポーネント

1. **Header（ヘッダー）**
   - ロゴ
   - ナビゲーション（必要に応じて）

2. **CourseCard（コースカード）**
   - サムネイル
   - タイトル
   - 講師名
   - ホバー効果

3. **Button（ボタン）**
   - プライマリスタイル
   - セカンダリスタイル
   - サイズバリエーション

4. **SectionList（セクションリスト）**
   - 折りたたみ可能
   - 動画リスト表示

5. **VideoPlayer（動画プレーヤー）**
   - YouTube埋め込み
   - レスポンシブ対応

## インタラクション

### アニメーション
- **ページ遷移**: スムーズなトランジション
- **ホバー効果**: カードの浮き上がり、色の変化
- **ローディング**: スピナーまたはスケルトンローディング

### ユーザーフロー
1. トップ画面でコースを選択
2. コース詳細ページで情報を確認
3. 「コースを見る」ボタンをクリック
4. 動画視聴ページで動画を視聴
5. セクションリストから動画を選択して切り替え
6. 動画終了後、次の動画に進む

## レスポンシブデザイン

### ブレークポイント（Tailwind CSS基準）
- **sm**: 640px以上（モバイル横向き）
- **md**: 768px以上（タブレット）
- **lg**: 1024px以上（デスクトップ）
- **xl**: 1280px以上（大型デスクトップ）

### モバイル対応
- 動画視聴ページのセクションリストは折りたたみ可能またはドロワー形式
- タッチ操作に最適化
- フォントサイズの調整

## アクセシビリティ

- 適切なコントラスト比の確保
- キーボードナビゲーション対応
- スクリーンリーダー対応（aria-labelなど）
- フォーカス状態の明確な表示
