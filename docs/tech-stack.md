# 技術スタック

## フロントエンドフレームワーク
- **Next.js 16.0.5**
  - App Routerを使用
  - サーバーサイドレンダリング（SSR）対応
  - ファイルベースルーティング

## UIライブラリ
- **React 19.2.0**
  - 最新のReactバージョンを使用
  - コンポーネントベースの開発

## スタイリング
- **Tailwind CSS 4**
  - ユーティリティファーストのCSSフレームワーク
  - レスポンシブデザインに対応

## 言語
- **TypeScript 5**
  - 型安全性を確保
  - 開発効率の向上

## 動画埋め込み
- **YouTube埋め込みAPI**
  - iframeを使用した動画埋め込み
  - YouTube Player APIの検討（必要に応じて）

## 開発ツール
- **ESLint**
  - コード品質の維持
  - Next.js用の設定を使用

## パッケージマネージャー
- npm（package-lock.jsonを使用）

## 今後の検討事項
- 状態管理ライブラリ（必要に応じて）
  - Zustand、Jotai、Recoilなどの検討
- データフェッチング
  - Next.jsのServer Componentsを活用
  - 必要に応じてAPI Routesの実装
- データベース（将来的に）
  - 認証・決済機能追加時に検討
- デプロイメント
  - Vercel、Netlifyなどの検討

## 開発環境
- Node.js 18以上推奨
- モダンブラウザ対応（Chrome、Firefox、Safari、Edge）
