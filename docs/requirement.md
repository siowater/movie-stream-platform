# 動画配信プラットフォーム 要件定義

## 概要
Udemyのような動画配信プラットフォームを作成します。学生が講師が配信する動画を閲覧できるアプリケーションです。

## 基本方針
- **デモ版のため認証機能は実装しない**（後回し）
- **決済機能は実装しない**（後回し）
- **誰でも無料で動画を閲覧可能**

## 機能要件

### 1. 動画の表示方法
- 動画は**YouTubeの埋め込み**を使用
- Udemyのように**セクションごとに動画を分類**
- 一つの動画を見終わったら、続いて次の動画を見ることができる

### 2. トップ画面（コース一覧ページ）
- 複数のコースが配置されている
- 各コースをクリックすると、そのコースの詳細ページに遷移する

### 3. コース詳細ページ
- 講座の詳細情報を表示
- 「コースを見る」ボタンを配置
- 「コースを見る」ボタンをクリックすると、動画視聴ページに遷移

### 4. 動画視聴ページ
- Udemyのようにセクションごとに動画を表示
- セクションごとに動画を順番に見ていくことができる
- 一つの動画を見終わったら、次の動画に進むことができる

## 技術要件
- Next.jsを使用したWebアプリケーション
- YouTube埋め込み動画の実装

## 今後の拡張予定
- 認証機能（ユーザー登録・ログイン）
- 決済機能（有料コースの購入）
